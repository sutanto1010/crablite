The repository is a two-service monorepo: `backend/` (Axum + SQLx) serves both the REST API and the static frontend assets under `/dist`, while `frontend/` (SolidJS + Vite) builds to that directory. The top-level `Dockerfile` orchestrates the build in three stages — Node/pnpm for the frontend, Rust/cargo for the backend, then an Alpine runtime image that copies both artifacts so the backend serves the SPA at port 3000. Cross-child contracts are purely HTTP over localhost: the frontend calls the backend's API endpoints (authenticated via the `API_KEY` environment variable), and the AI assistant feature is shared through OpenAI env vars (`OPENAI_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_MODEL`) consumed only by the backend. CI lives in `.github/workflows/docker-publish.yml` and Dependabot in `.github/dependabot.yml`; releases are produced by manually building both sides and packaging the binary with the `frontend/dist` tree.
