Development runs the two services independently (`cd frontend && pnpm start` on :5173, `cd backend && cargo run` on :3000); production is intended via `docker run -p 3000:3000 -v sqlite.db:/app/db/sqlite.db -e API_KEY=... wangyucode/rust-sqlite-webui`. Release builds require running `pnpm build` in `frontend/` followed by `cargo build --release` in `backend/`, then packaging the binary together with `frontend/dist/` per the README script.
