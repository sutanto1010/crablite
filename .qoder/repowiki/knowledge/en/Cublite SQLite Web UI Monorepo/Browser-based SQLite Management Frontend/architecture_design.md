Single-page app rooted at `src/main.tsx` → `App.tsx`, which composes top-level layout components (`Navbar`, `Sidebar`, `Editor`, `Toolbar`, `ResultTable`, `AuthModal`) defined under `src/components/`. Application state is centralized in `src/lib/store.ts`, which exposes SolidJS `createSignal`-based signals (tables, sqlContent, queryResult, apiKey, etc.) and orchestrates side effects like auto-refreshing tables after DDL/DML. The HTTP layer lives in `src/lib/api.ts`, wrapping `fetch` calls to relative endpoints (`./api/tables`, `./api/query`, `./api/correct`, `./api/db-files`, `./api/connect`, `./api/health`) and centralizing the `x-api-key` header plus 401 handling via an optional `onUnauthorized` callback that opens the auth modal. Components are pure presentational consumers of the store; there is no routing or nested sub-packages — dependency direction is strictly components → store → api.

Build toolchain: Vite 7 with `vite-plugin-solid` for JSX compilation, Tailwind CSS v4 via `@tailwindcss/vite` plus DaisyUI v5 for prebuilt component classes. Package manager is pnpm (enforced by `pnpm-workspace.yaml` and the `packageManager` field).
