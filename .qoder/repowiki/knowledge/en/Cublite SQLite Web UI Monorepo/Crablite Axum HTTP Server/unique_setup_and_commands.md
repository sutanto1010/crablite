Binary listens on `0.0.0.0:3000` (overridable via `PORT`); requires a `dist/` directory for the frontend fallback served via `ServeDir::new("dist")`; an `API_KEY` environment variable (or `.env`) controls the `x-api-key` header check; `RUST_LOG` controls tracing verbosity; `DB_DIR` sets the SQLite data directory (default `db`); `OPENAI_API_KEY` / `OPENAI_BASE_URL` / `OPENAI_MODEL` configure the AI correction endpoint.
