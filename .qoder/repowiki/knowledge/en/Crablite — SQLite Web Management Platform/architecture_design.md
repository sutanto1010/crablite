The repo is split into two independent services — `backend/` (Axum + SQLx) and `frontend/` (SolidJS + Vite) — with no shared code. Cross-child communication is strictly HTTP: the frontend calls the backend's REST endpoints over localhost, authenticated via the `API_KEY` environment variable, while AI-assisted SQL correction uses OpenAI env vars (`OPENAI_API_KEY`, `OPENAI_BASE_URL`, `OPENAI_MODEL`) consumed only by the backend. The top-level `Dockerfile` orchestrates the build in three stages (Node/pnpm for the frontend, Rust/cargo for the backend, Alpine runtime) so the compiled binary statically serves `frontend/dist` under `/`. CI (`/.github/workflows/docker-publish.yml`) and Dependabot (`/.github/dependabot.yml`) operate at the repo root to publish the combined image; release artifacts are assembled by copying `frontend/dist` alongside the built binary per the README script.
